## Latest GitHub Updates

- **GitHub Actions artifact uploads now use v4 for better reliability.** (Source: GitHub Changelog)

- **Awesome Copilot Workflows** ([Awesome Copilot Workflows](https://awesome-copilot.github.com/workflows/))
  - *Daily Issues Report*: Generates a daily summary of open issues and recent activity as a GitHub issue. (Source: Awesome Copilot Workflows)
  - *OSPO Contributors Report*: Monthly contributor activity metrics across an organization’s repositories. (Source: Awesome Copilot Workflows)
  - *OSPO Organization Health Report*: Comprehensive weekly health report for a GitHub organization. Surfaces stale issues/PRs, merge time analysis, contributor leaderboards, and actionable items needing human attention. (Source: Awesome Copilot Workflows)
  - *OSPO Stale Repository Report*: Identifies inactive repositories in your organization and generates an archival recommendation report. (Source: Awesome Copilot Workflows)
  - *OSS Release Compliance Checker*: Analyzes a target repository against open source release requirements and posts a detailed compliance report as an issue comment. (Source: Awesome Copilot Workflows)
  - *Relevance Check*: Slash command to evaluate whether an issue or pull request is still relevant to the project. (Source: Awesome Copilot Workflows)
  - *Relevance Summary*: Manually triggered workflow that summarizes all open issues and PRs with a /relevance-check response into a single issue. (Source: Awesome Copilot Workflows)

Stay tuned for more updates from the [GitHub Blog](https://github.blog/latest/) and [Changelog](https://github.blog/changelog/).
